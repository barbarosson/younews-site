## Live links

- Store ID: `9P07VBL4760N`
- Web: https://apps.microsoft.com/detail/9P07VBL4760N
- Deep link: `ms-windows-store://pdp/?productid=9P07VBL4760N`

1. Open https://younews.media (Ctrl+F5).
2. Store buy button opens Store / PDP.
3. Paddle buy button opens overlay (after `clientToken` is set).
