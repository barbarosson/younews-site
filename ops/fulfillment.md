# Fulfillment — Microsoft Store

Purchases and licensing are handled by the Microsoft Store.
There is no Paddle checkout and no YN1 key email from this site.

## What customers get

1. Buy / try in Microsoft Store.
2. Install YOUNEWS (MSIX).
3. License follows their Microsoft account (see app `core/store_license.py`).

## Support

- Billing / refunds → Microsoft Store / Microsoft account support.
- App questions → hello@younews.media

Buy buttons are live via `store.js` (PFN deep link).
